# Money — личный финансовый дашборд

Простое веб-приложение для учёта доходов и расходов. Работает прямо в браузере, без сервера и регистрации.

## Возможности
- KPI: доход, расход, остаток, норма сбережений
- Главная цель и цель на месяц с прогресс-барами
- График доходов, расходов и остатка за последние 6 месяцев
- Кольцевые диаграммы по категориям
- Фильтр по периоду, поиск и фильтр по типу операций
- Свои категории, валюта и цели в настройках
- Тёмная и светлая тема
- Данные сохраняются в браузере (localStorage), есть экспорт и импорт JSON
- Импорт банковских выписок: CSV/Excel (Т-Банк и др.) и PDF (Яндекс Банк, Озон Банк и др.) с автокатегориями, предпросмотром и защитой от дублей
- Работает как Telegram Mini App: тема Telegram, вибро-отклик, синхронизация данных между устройствами через Telegram CloudStorage

## Запуск
Откройте `index.html` в браузере.
